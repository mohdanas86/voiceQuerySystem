# Roadmap

## MVP Phase
- Record, transcribe, translate
- Phone validation
- Submit to API
- Store in MongoDB
- Send email
- Confirmation screen

## Phase 2
- Language auto-detection
- Admin view for submissions
- Export to CSV

## Phase 3
- Queue-based email delivery
- Analytics dashboard
- Multi-tenant support

## Future AI Features
- Intent classification
- Auto-prioritization
- Summary generation

## Scaling Plan
- Add cache for translation
- Add worker service for email
- Use CDN for static assets
