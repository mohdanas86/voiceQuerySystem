# Frontend Design System

## Design Principles
- Minimal and calm
- One primary action per screen
- Large touch targets
- Mobile-first
- Accessible color contrast

## Color Tokens
- Background: #0f1115
- Surface: #141922
- Surface Alt: #1b2230
- Primary: #4fd1c5
- Primary Dark: #2c8f86
- Text Primary: #f5f7fa
- Text Muted: #9aa3b2
- Error: #f87171
- Success: #34d399

## Typography
- Headings: "Sora", sans-serif
- Body: "Inter", sans-serif
- Base size: 16px
- Scale: 12, 14, 16, 20, 24, 32

## Spacing
- 4, 8, 12, 16, 24, 32, 48

## UI Elements
- Rounded cards: 16px radius
- Buttons: 14px radius, 44px height min
- Inputs: 12px radius

## Motion
- Page load fade-in 200ms
- Button hover 150ms
- Error shake 200ms

## Mobile-First Strategy
- Default layout for 360-430px width
- Single column layout
- Sticky primary action at bottom
